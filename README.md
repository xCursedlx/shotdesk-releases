# ShotDesk

**Приложение для Windows, которое раскладывает игровые скриншоты смены (GTA 5, сервер Majestic) по папкам само.** Нажали горячую клавишу — программа сняла кадр, прочитала плашки на экране и положила файл в нужное место: `Неделя / Ранг / Действие / Место`. Всё, в чём она не уверена, попадает в «На проверку», где вы разбираете кадр парой кликов. Время везде московское.

Текст на экране читает встроенный в Windows OCR: интернет для этого не нужен, скриншоты никуда не отправляются.

**[Скачать последнюю версию](https://github.com/xCursedlx/shotdesk-releases/releases/latest)** (файл `ShotDesk_Setup_x.y.z.exe`) · [как установить](#установка) · [возможности](#возможности) · [горячие клавиши](#горячие-клавиши)

## Возможности

### Съёмка и раскладка
- Три горячие клавиши для города, Сэнди-Шорса и Палето-Бэя (по умолчанию Ctrl+Num7, Num8, Num9). Любую можно заменить одной клавишей без Ctrl/Alt/Shift: цифровой блок, F-клавиши, стрелки и другие. Такие клавиши работают, только пока окно игры в фокусе.
- Программа сама определяет действие по плашке в игре: таблетки, вакцины, ПМП, справки, дежурство, бриффинг и другие. Свои виды действий и названия папок добавляются в настройках.
- Папки создаются сами по схеме «Неделя / Ранг / Действие / Место», для части действий ещё и по смене (день или ночь).

### Окно «На проверку» (Ctrl+P)
- Сюда уходят кадры, в которых программа не уверена или нашла проблему (например, бодикамера выключена). Для каждого указана причина.
- Выберите действие, и кадр уйдёт в нужную папку. Можно вернуть кадр обратно (Ctrl+Shift+P) и отменить любой перенос (Ctrl+Z).
- Кадр, разобранный во время бриффинга, копируется и в папку бриффинга.

### Главное окно
- Дерево недель и папок, сетка миниатюр с цветом и подписью действия, сортировка (новые, по действию, по месту).
- Открытие скриншота, копирование картинки в буфер (Ctrl+C), перенос (Ctrl+M), перенос в свою папку (Ctrl+Shift+M), удаление в корзину (Del) с отменой.

### Бодикамера
- Плашка бодикамеры нужна, чтобы кадр был принят. Счётчик «с начала записи» сверяется с прошлым снимком: за N секунд он должен вырасти на N. Если камера выключалась, кадр уходит «На проверку» с пояснением.
- Проверки камеры по таймеру и вручную (Ctrl+K), напоминание включить камеру, журнал проверок и окно диагностики.
- Если плашку закрыла карточка вызова или чат, программа дочитывает её отдельным запросом.

### Дежурства и бриффинги
- Расписание (Ctrl+R): слоты проверок, пауза, автоматическое завершение. Дежурство засчитывается как час.
- Новое дежурство (Ctrl+D) и новый бриффинг (Ctrl+B). Если они пересекаются, форма предупредит.
- Напоминания со звуком и карточками поверх игры, тихий режим. Звуки синтезирует сама программа.

### Отчёт за неделю (Ctrl+Shift+W)
- Баллы по действиям и по дням, профили «Средний» и «Старший», цель по баллам (по умолчанию 500).
- Ручные счётчики для действий, которые не попали в кадр. Отчёт копируется в буфер или сохраняется в файл.

### Проверка папок
- Находит дубли (в корзину) и недостающие копии кадров в бриффингах и дежурствах. Сначала показывает, что нашла, и только потом исправляет.

### Настройки (Ctrl+,)
Одиннадцать разделов: основное, внешний вид, данные и обновления, съёмка, клавиши, проверки и напоминания, уведомления и звук, виды действий, баллы, плашки действий, игнорируемые плашки.

### Оформление и удобства
- Тёмная и светлая темы, день и ночь переключаются автоматически по московскому времени. Анимации можно выключить.
- Значок в трее, автозапуск, закрытие в трей.
- Резервные копии настроек раз в день (хранится заданное число, восстановление из копии).
- Автообновление: программа сама находит новую версию и предлагает обновиться.

## Горячие клавиши

**В игре (по умолчанию):** Ctrl+Num7 — город, Ctrl+Num8 — Сэнди-Шорс, Ctrl+Num9 — Палето-Бэй.

**В окне программы:**

| Клавиша | Действие |
|---|---|
| Ctrl+P | «На проверку» |
| Ctrl+R | расписание |
| Ctrl+K | проверки бодикамеры |
| Ctrl+Shift+W | отчёт за неделю |
| Ctrl+, | настройки |
| Ctrl+D / Ctrl+B | новое дежурство / новый бриффинг |
| Ctrl+M / Ctrl+Shift+M | перенести / в свою папку |
| Ctrl+Z | отменить перенос |
| Ctrl+C | копировать картинку |
| Del | в корзину |
| Enter | открыть скриншот; подтвердить |
| Ctrl+Shift+F / Ctrl+N | новая папка / новая неделя |
| F5 | обновить список |
| Esc | отмена |

## Установка

**Что понадобится**
- Windows 10 (версия 2004 и новее) или Windows 11, 64 бита.
- Игра в **оконном режиме без рамки** (Borderless). В полноэкранном режиме Windows не даёт снять кадр.
- **Русский пакет распознавания текста Windows.** Без него плашки не читаются. Установщик может поставить его сам (нужны права администратора и интернет).

**Шаги**
1. Скачайте `ShotDesk_Setup_x.y.z.exe` из [последнего релиза](https://github.com/xCursedlx/shotdesk-releases/releases/latest) и запустите.
2. Если Windows показала «Windows защитила ваш компьютер» (SmartScreen), нажмите **Подробнее → Выполнить в любом случае**. Установщик без платной подписи издателя, Windows его просто не знает.
3. Права администратора для самой программы не нужны, она ставится в вашу папку пользователя. В установщике можно включить автозапуск, ярлык и установку русского пакета OCR.
4. При первом запуске откроется мастер: папка для скриншотов, ваш ранг, горячие клавиши. Потом всё меняется в настройках.

## Обновления

При запуске программа проверяет новую версию, предлагает обновиться, скачивает установщик, проверяет контрольную сумму и подпись и ставит его. Настройки и скриншоты не затрагиваются. Отключить: «Настройки → Данные и обновления».

## Если что-то не работает

- **Плашки не распознаются:** нет русского пакета OCR. В PowerShell от имени администратора:

      Add-WindowsCapability -Online -Name "Language.OCR~~~ru-RU~0.0.1.0"

  Проверка (должно быть Installed): `Get-WindowsCapability -Online -Name "Language.OCR~~~ru-RU*"`. Затем перезагрузите компьютер.
- **Кадр чёрный:** игра в полноэкранном режиме, переключите на Borderless.
- **Клавиша не срабатывает:** для цифрового блока нужен NumLock; одиночные клавиши работают, только пока окно игры в фокусе.
- **Нужна помощь:** в настройках есть кнопка «Скопировать отчёт для разработчика». Пришлите этот текст.

## Где хранятся данные

| Что | Где |
|---|---|
| Настройки, состояние, расписание | `%APPDATA%\ShotDesk` |
| Журналы | `%APPDATA%\ShotDesk\logs` |
| Резервные копии | `%APPDATA%\ShotDesk\backups` |
| Скриншоты | папка, выбранная при первом запуске |

При удалении (Параметры → Приложения → ShotDesk) эти данные остаются, их можно удалить вручную.
