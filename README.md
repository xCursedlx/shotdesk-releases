# ShotDesk: установщики

Здесь выкладываются установщики **ShotDesk**: программы для Windows, которая раскладывает игровые скриншоты смены (GTA5, Majestic) по папкам. Нажали горячую клавишу, программа сняла кадр, прочитала плашки действий и положила файл в нужную папку недели, ранга и места. Всё, что не удалось определить, попадает в «На проверку».

Скачать последнюю версию: раздел [Releases](../../releases/latest), файл `ShotDesk_Setup_x.y.z.exe`.

## Что умеет

- **Раскладка кадров.** Горячие клавиши для города, Сэнди-Шорс и Палето (по умолчанию Ctrl+Num7, Num8, Num9; можно назначить и одну клавишу без модификаторов). Папки по схеме «Неделя / Ранг / Действие / Место».
- **Свои действия и папки.** Таблетки, вакцины, ПМП, справки и любые свои виды действий с цветными плашками.
- **«На проверку».** Спорные кадры собираются отдельно: просмотр, перенос в нужное действие, отмена переноса.
- **Бодикамера.** Кадр принимается, только если на нём видна плашка камеры и счётчик «с начала записи» идёт. Выключенная или выключавшаяся камера отправляет кадр на проверку с причиной. Есть автоматическая проверка по таймеру и напоминания.
- **Дежурства и бриффинги.** Расписание, слоты проверок, паузы, отдельные папки и копирование кадров в бриффинг.
- **Отчёт за неделю.** Баллы, цель по баллам, ручные счётчики.
- **Удобства.** Значок в трее, автозапуск, тёмная и светлая тема (день и ночь меняются сами по московскому времени), звуки и режим тишины в игре, резервные копии настроек.
- **Автообновление.** При запуске программа сама проверяет новую версию и предлагает обновиться.

Время везде московское. Распознавание текста выполняется на вашем компьютере встроенным средством Windows, кадры никуда не отправляются.

## Что понадобится

- Windows 10 (версия 2004 и новее) или Windows 11, 64-битная.
- Игра в **оконном режиме без рамки** (Borderless). В полноэкранном режиме Windows не даёт снять кадр.
- **Русский пакет распознавания текста Windows.** Без него программа не прочитает плашки.

## Установка

1. Откройте PowerShell **от имени администратора** и один раз поставьте русский пакет OCR:

       Add-WindowsCapability -Online -Name "Language.OCR~~~ru-RU~0.0.1.0"

   Проверка (должно быть `Installed`):

       Get-WindowsCapability -Online -Name "Language.OCR~~~ru-RU*"

   После установки перезагрузите компьютер.
2. Скачайте и запустите `ShotDesk_Setup_x.y.z.exe`. Права администратора не нужны, программа ставится в папку пользователя. В установщике можно включить автозапуск и ярлык на рабочем столе.
3. Windows может показать предупреждение SmartScreen («Windows защитила ваш компьютер»): установщик не подписан цифровой подписью. Нажмите **Подробнее → Выполнить в любом случае**.
4. При первом запуске откроется мастер: папка для скриншотов, ваш ранг и горячие клавиши. Всё это потом меняется в «Настройки».

## Горячие клавиши в окне программы

| Клавиши | Действие |
|---|---|
| Ctrl+P | Окно «На проверку» |
| Ctrl+Z | Отменить последний перенос |
| Ctrl+D / Ctrl+B | Новое дежурство / новый бриффинг |
| Ctrl+R | Расписание |
| Ctrl+Shift+W | Отчёт за неделю |
| Ctrl+K | Проверка бодикамеры |
| Ctrl+N | Новая неделя |
| Ctrl+, | Настройки |
| F5 | Обновить список |

## Обновление

Ничего скачивать вручную не нужно. При запуске программа проверяет новую версию и спрашивает: «Доступна версия X. Обновить сейчас?». После согласия она скачивает установщик, ставит его и запускается заново. Настройки и скриншоты сохраняются. Кнопка «Версия X: обновить» остаётся в верхней панели, если вы отказались. Проверить вручную: «Настройки → Основное → Обновления → Проверить сейчас». Установленная версия показана рядом с названием в окне.

## Если что-то не работает

- **Плашки не читаются, пишет «распознавание не работает».** Не установлен русский пакет OCR (см. «Установка», п. 1).
- **Кадр чёрный.** Игра в полноэкранном режиме: переключите на Borderless.
- **Кадр уходит «На проверку».** Причина записана рядом с кадром в окне проверки. Чаще всего это нет плашки действия или плашки бодикамеры, либо камера была выключена.
- **Не обновляется.** Проверьте, что есть интернет, и нажмите «Проверить сейчас». Установщик новой версии всегда можно скачать здесь вручную и запустить поверх старой: настройки сохранятся.
- **Отчёт о проблеме.** В «Настройки» и в окне проверки бодикамеры есть кнопка «Скопировать отчёт для разработчика».

## Удаление

Параметры → Приложения → ShotDesk → Удалить. Настройки (`%APPDATA%\ShotDesk`) и скриншоты остаются, их можно удалить вручную.
