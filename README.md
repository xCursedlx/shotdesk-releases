# ShotDesk: установщики

ShotDesk — приложение для Windows, которое раскладывает игровые скриншоты смены (GTA 5, сервер Majestic) по папкам: таблетки, вакцины, ПМП, справки и ваши собственные действия. Нажали горячую клавишу, программа сняла кадр, прочитала плашки на экране и положила файл в нужную папку недели, ранга и места. Что не удалось определить, попадает в «На проверку». Время везде московское.

Распознавание текста выполняет встроенный в Windows OCR. Интернет для него не нужен, а скриншоты никуда не отправляются.

## Скачать

Последняя версия: раздел [Releases](https://github.com/xCursedlx/shotdesk-releases/releases/latest), файл `ShotDesk_Setup_x.y.z.exe`. То же самое лежит на Яндекс Диске: ссылка у того, кто вам программу дал.

## Что понадобится

- Windows 10 (версия 2004 и новее) или Windows 11, 64 бита.
- Игра в **оконном режиме без рамки** (Borderless). В полноэкранном режиме Windows не даёт снять кадр.
- **Русский пакет распознавания текста Windows.** Без него плашки не читаются. Установщик может поставить его сам (нужны права администратора и интернет), или см. «Если что-то не работает».

## Установка

1. Запустите `ShotDesk_Setup_x.y.z.exe`.
2. Если Windows показала «Windows защитила ваш компьютер» (SmartScreen), нажмите **Подробнее → Выполнить в любом случае**. Установщик без платной подписи издателя, Windows его просто не знает.
3. Права администратора для самой программы не нужны, она ставится в вашу папку пользователя.
4. В установщике можно включить автозапуск и ярлык на рабочем столе.
5. При первом запуске откроется мастер: папка для скриншотов, ваш ранг, горячие клавиши. Потом всё меняется в настройках.

## Что умеет

- **Раскладка по папкам:** кадр попадает в «Неделя / Ранг / Действие / Место», где действие определяется по плашке в игре. Горячие клавиши для города, Сэнди-Шорса и Палето (по умолчанию Ctrl+Num7, Num8, Num9).
- **«На проверку»:** спорные кадры собираются в одном окне (Ctrl+P): выберите действие, и кадр переедет куда нужно. Любой перенос можно отменить (Ctrl+Z).
- **Бодикамера:** программа проверяет, что камера действительно пишет, и напоминает её включить.
- **Дежурства и бриффинги:** расписание, слоты проверок, пауза, напоминания со звуком поверх игры.
- **Отчёт за неделю** (Ctrl+Shift+W): баллы по действиям и по дням, ручные счётчики, цель по баллам. Копируется в буфер или сохраняется в файл.
- **Удобства:** тёмная и светлая темы, значок в трее, автозапуск, резервные копии настроек, миниатюры с цветом действия, копирование картинки в буфер.

## Обновления

Обновления приходят сами: при запуске программа проверяет новую версию, предлагает обновиться, скачивает и ставит её. Настройки и скриншоты не трогаются. Установщик из сети проверяется по контрольной сумме и подписи. Отключить проверку можно в «Настройки → Данные и обновления».

## Если что-то не работает

- **Плашки не распознаются:** не установлен русский пакет OCR. В PowerShell от имени администратора:

      Add-WindowsCapability -Online -Name "Language.OCR~~~ru-RU~0.0.1.0"

  Проверка (должно быть Installed): `Get-WindowsCapability -Online -Name "Language.OCR~~~ru-RU*"`. Затем перезагрузите компьютер.
- **Кадр чёрный:** игра в полноэкранном режиме, переключите на Borderless.
- **Горячая клавиша не срабатывает:** для цифровой клавиатуры должен быть включён NumLock; одиночные клавиши работают, только пока окно игры в фокусе.
- **Нужна помощь:** в «Настройки» (и в окне «Проверки бодикамеры») есть кнопка «Скопировать отчёт для разработчика». Пришлите этот текст.

## Где хранятся данные

| Что | Где |
|---|---|
| Настройки, состояние, расписание | `%APPDATA%\ShotDesk` |
| Журналы | `%APPDATA%\ShotDesk\logs` |
| Резервные копии | `%APPDATA%\ShotDesk\backups` |
| Скриншоты | папка, выбранная при первом запуске |

## Удаление

Параметры → Приложения → ShotDesk → Удалить. Настройки и скриншоты остаются, их можно удалить вручную.
