# ShotDesk: установщики

Приложение для Windows: раскладывает скриншоты смены GTA 5 / Majestic по папкам «Неделя / Ранг / Действие / Место». Нажали горячую клавишу — кадр снят, плашки прочитаны, файл на своём месте. Спорное уходит «На проверку». Работает без интернета, скриншоты никуда не отправляются.

**Скачать:** [последний релиз](https://github.com/xCursedlx/shotdesk-releases/releases/latest), файл `ShotDesk_Setup_x.y.z.exe`.

**Нужно:** Windows 10 (2004+) или 11, игра в режиме Borderless, русский пакет распознавания текста Windows. SmartScreen: «Подробнее → Выполнить в любом случае».

**Умеет:** проверку бодикамеры, дежурства и бриффинги с напоминаниями, отчёт и баллы за неделю, тёмную и светлую темы, трей, автозапуск, автообновление.

Горячие клавиши по умолчанию: Ctrl+Num7 / Num8 / Num9 (город, Сэнди-Шорс, Палето), Ctrl+P («На проверку»), Ctrl+Shift+W (отчёт).
