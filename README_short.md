# ShotDesk

Приложение для Windows: раскладывает скриншоты смены GTA 5 / Majestic по папкам `Неделя / Ранг / Действие / Место`. Нажали горячую клавишу — кадр снят, плашки прочитаны, файл на месте. Спорное уходит «На проверку». Работает без интернета, скриншоты никуда не отправляются.

## Что умеет
- **Раскладка по папкам:** действие определяется по плашке, свои виды действий добавляются в настройках.
- **«На проверку» (Ctrl+P):** спорные кадры с причиной, перенос в пару кликов, отмена (Ctrl+Z).
- **Бодикамера:** проверка записи, напоминания, журнал.
- **Дежурства и бриффинги:** расписание, слоты проверок, напоминания со звуком.
- **Отчёт за неделю (Ctrl+Shift+W):** баллы, столбики по дням, ручные счётчики, цель.
- **Проверка папок:** дубли и недостающие копии.
- **Удобства:** тёмная и светлая темы, трей, автозапуск, резервные копии, автообновление.

**Клавиши в игре по умолчанию:** Ctrl+Num7 / Num8 / Num9 — город / Сэнди-Шорс / Палето.
